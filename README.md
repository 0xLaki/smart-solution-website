# Smart Solution Website

Репозиторий сайта команды **Smart Solution**.

Сейчас проект находится на стадии постановки задачи. До начала реализации нужно согласовать цели сайта, аудиторию, контент, визуальные материалы и технические ограничения. Рабочие задачи ведутся в [GitHub Issues](https://github.com/astor-hospitality/smart-solution-website/issues) и на [GitHub Project-доске](https://github.com/users/michaelwelly/projects/4).

## Подготовка к релизу — 06.10.2026

Пока это бриф и контент, не приложение. Стек, сборка, автотесты и production
deployment не определены; команды из Astor или VEDAL сюда не переносятся.

- [ ] Заказчик согласовал [бриф](docs/BRIEF.md), аудиторию и MVP.
- [ ] Рома подготовил реализацию в PR, Егор проверил результат.
- [ ] Подтверждены контент, права на материалы и [чек-лист](docs/CONTENT_CHECKLIST.md).
- [ ] После выбора стека документированы запуск, тесты, CI и hosting.
- [ ] Перед публикацией проверены мобильный UX, формы, метаданные, privacy и откат.

Документационный тег не означает запуск сайта.

## Базовый процесс

1. Уточнить и зафиксировать требования в брифе.
2. Согласовать структуру и прототип.
3. Выбрать стек и платформу размещения.
4. Реализовать MVP сайта.
5. Провести проверку на мобильных устройствах, настроить метаданные и публикацию.
