# Smart Solution Website

Сайт команды **Smart Solution**: публичная страница о команде для её заказчиков и
партнёров. Предполагаемый состав MVP (гипотеза из [брифа](docs/BRIEF.md), требует
подтверждения): первый экран с позиционированием и призывом к действию, «О команде»,
проекты/достижения, контакты, подвал с юридической информацией.

Репозиторий публичный: секреты, доступы и адреса серверов сюда не попадают.

## Стек и структура

Статический сайт без фреймворка и без npm-зависимостей. Страницы собирает скрипт
`white/src/build.js` (Node 18+) из шаблона и данных; на выходе обычные HTML, шрифты и
картинки, которые отдаёт любой веб-сервер.

```
.
├── white/
│   ├── src/
│   │   ├── build.js         # сборка всех страниц
│   │   ├── template.html    # шапка, стили и скрипты всех страниц, тексты главной
│   │   ├── products.js      # продукты, работы и команда (тексты и картинки)
│   │   ├── illus.js / .css  # живые картинки на страницах продуктов
│   │   ├── assistant.html   # помощник «Смарт»
│   │   ├── assets/          # шрифт Manrope, фото команды, обложки работ
│   │   └── private/         # коммерческий шрифт логотипа TT Travels (не в git)
│   ├── DESIGN.md            # дизайн-система
│   └── index.html, services/, works/, team/, assets/, robots.txt, sitemap.xml
│                            # собранное превью (генерируется, руками не правится)
├── logo/logo-nabroski.html  # логотип: из него сборка берёт знак
├── docs/                    # бриф и чек-лист контента
└── README.md
```

## Локальный запуск, сборка, деплой

Сборка (нужен Python с `fontTools`: он режет шрифт логотипа):

```bash
node white/src/build.js
python -m http.server 8099 -d white   # открыть http://localhost:8099
```

Без `white/src/private/travels-800.ttf` сборка тоже проходит, только надпись в логотипе
будет системным шрифтом. Тексты продуктов, работ и команды — в `white/src/products.js`,
остальные — в `white/src/template.html`; после правки сайт пересобирается.

### Деплой

Сайт стоит на Vercel (проект `smart-soultion`, команда `laki10`); собирает и выкладывает Рома:
у него лицензионный шрифт логотипа.

1. Собрать версию для домена:

   ```bash
   SITE_URL=https://smart-soultion.com SITE_INDEX=1 OUT=_local/release node white/src/build.js
   ```

   В `_local/release/` (не в git) получится сайт, открытый для поисковиков: canonical,
   `sitemap.xml`, `robots.txt`. Сборка без этих переменных — закрытое превью (`noindex`).
2. Скопировать содержимое `_local/release/` в папку проекта Vercel и выполнить
   `vercel deploy --prod`. В `vercel.json` там: `www` переадресуется на `smart-soultion.com`,
   служебный адрес `smart-soultion.vercel.app` отдаётся с `X-Robots-Tag: noindex`.

DNS на REG.RU (один раз; Vercel сам выпустит сертификат HTTPS):

| Тип | Имя | Значение |
|-----|-----|----------|
| A | `@` | `216.198.79.1` |
| A | `@` | `64.29.17.1` |
| CNAME | `www` | `84a62c1163045be7.vercel-dns-017.com.` |

Старые записи `A @` и `A www` (сервер команды) удалить. После запуска — добавить сайт в
Яндекс Вебмастер и Google Search Console и отправить `https://smart-soultion.com/sitemap.xml`.

Позже (решение Егора — «потом добавим»): счётчик Vercel Web Analytics (без cookie, включается
в настройках проекта, на страницы добавляется его скрипт) и страница политики обработки
персональных данных для формы.

## Контент и правки

Контент сайта сейчас — документы в `docs/`:

- `docs/BRIEF.md` — заполнять ответами по разделам 1–7. Структура MVP в разделе 3 —
  гипотеза, её подтверждают до разработки.
- `docs/CONTENT_CHECKLIST.md` — отмечать `[x]` по мере получения материалов; права
  на фото и тексты подтверждать до публикации.

Правила правок:

1. Ветка от `main`, изменения через PR; в `main` напрямую не коммитим.
2. Markdown по `.editorconfig`: UTF-8, LF, 2 пробела, завершающий перенос строки.
3. Если в PR принято новое решение (стек, хостинг, домен, интеграция) — отразить
   его в README и в соответствующей задаче.
4. Секреты, токены, адреса серверов и персональные данные в репозиторий не попадают.
